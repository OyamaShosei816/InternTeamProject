# キャラクター性能の調整

`Assets/Prefab/Kazuma/Player.prefab` の `KazumaDragPlayer` で、
「キャラクター性能：パリィ・キュー・攻撃力」を開いて調整します。
この試作の「キュー」は水風船です。基本値はすべて1倍です。

| 項目 | 2倍にした場合 |
| --- | --- |
| パリィ範囲 | プレイヤー側のパリィ半径が2倍。被弾半径・受付時間は維持 |
| キュー速度 | 公転の目標速度、投擲速度の上限、フリック加速が2倍 |
| キュー成長速度 | 実際の回転に対して強化進捗が2倍。移動しながら回す条件は必要 |
| 攻撃力 | 同じ投擲速度なら弱点へのダメージが2倍 |
| キュー再生産速度 | 再出現までの待ち時間が半分 |
| キュー当たり範囲 | 風船の半径と表示サイズが2倍。敵弾消去とボス命中へ反映 |

最終倍率は **Inspectorの基本倍率 × パッシブ補正倍率** です。
公転はばね・紐で動くため、速度倍率は公転目標の速さを変更します。
飛行中の風船の速度は投げた瞬間に確定し、その後の速度スキル変更は次の投擲へ反映します。
攻撃力は速度由来の基本ダメージ（8～60）へ後から掛けるため、補正後は60を超えられます。

将来のスキル管理は装備スキルの倍率を集計して、次のAPIへ渡します。
指定した6種類の補正をまとめて置き換えるので、変更のたびに全体を渡してください。

```csharp
// 例：パリィ範囲1.5倍、攻撃力2倍、再生産速度1.25倍。
player.Parameters.SetPassiveMultipliers(
    parryRange: 1.5f,
    attack: 2f,
    cueReproduction: 1.25f);

// 装備スキルをすべて外した場合。Inspectorの基本値は保持する。
player.Parameters.ResetPassiveMultipliers();
```

補正はリトライで保持されます。スキル取得・装備・重複集計・保存の仕組みは、
後のパッシブスキル実装でこの入口へ接続します。
