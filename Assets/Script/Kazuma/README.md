# Kazuma 水風船プロトタイプ

`Assets/Scenes/Kazuma.unity` を開いて Play。Game ビューは **9:16（例：540×960）** 推奨です。横長でもプレイ範囲全体が映るようカメラを調整します。背景オブジェクト、UI、HPバー、音は追加していません。

## 操作と遊び

- 画面のどこでも左ボタンを押しながらドラッグすると、水色のプレイヤーがその移動量に追従します。Android は指1本で同じ操作です。押し始めに位置は飛びません。
- 押している間、緑の水風船が周回します。プレイヤーを動かすとばねのように引っ張られ、慣性で軌道が変わります。
- **プレイヤーを動かしながら実際に3周**するとレベル2、さらに3周でレベル3です。静止して押し続けるだけでは強化されません。
- 強さは **緑＝1、黄＝2、ピンク＝3**。敵弾も同じ色分けです。球は同じ強さ以下の弾を消します。ひもには弾消し判定がありません。
- ボタン／指を離すと、球の現在の速度方向に投げます。離す直前のフリックで投げる方向に力を足せます。速いほどダメージが増えます。
- 赤いボスの手前にある**黄色い球が弱点**です。投げた球を弱点に当てるとダメージ、本体への命中は無効です。投擲後、命中・画面外・飛行時間切れで0.65秒の回復待ちに入り、新しい球が戻ります。
- 発射直後は0.22秒無敵。発射から0.12秒以内に強攻撃（ピンクの弾）を受けるとパリィし、画面内の全弾を消します。
- 被弾するとプレイヤーが赤くなり停止。ボスHPを削り切るとボスが消え、プレイヤーが緑になってクリアします。0.75秒後から新しくクリック／タップすると再開します。PCでは `R` でもリセットできます。
- HPと結果はUnity Consoleでも確認できます。

## 構成・調整

- `Assets/Prefab/Kazuma/Player.prefab`：ドラッグ操作。
- `Assets/Prefab/Kazuma/WaterBalloon.prefab`：ばね、周回、強化、投擲、ひも。
- `Assets/Prefab/Kazuma/EnemyBullet.prefab`：敵弾。
- シーンの `Kazuma Gameplay Prototype`：ボスHP、発射間隔、無敵・パリィ時間。
- プレハブの `KazumaWaterBalloon`：ばね係数、回転速度、ひもの長さ、フリックの強さ、回復時間。

PDFに数値のない射出速度、ボスHP、弾幕、無敵時間、球の補充・再開方法は、繰り返し試せる仮仕様です。最終ページのメモや完成イメージの背景・UIは実装対象にしていません。

当たり判定は移動前後の球同士の連続判定です。UnityのRigidbodyやColliderのトリガー通知には依存しません。ひもは描画専用です。新しい挙動は `KazumaPrototype` 名前空間に閉じており、既存の `PlayerTouchMove` と他シーンは変更しません。

## 検証・再構築

`Tools > Kazuma > Validate gameplay in Play Mode` で保存済みシーンを開き、入力、3段階強化、慣性、フリック、弾消し、パリィ、失敗、クリア、リセットを検証します（編集作業を保存してから実行）。

`Tools > Kazuma > Rebuild gameplay prototype` はプロトタイプのルート、3つのプレハブとマテリアルを初期設定に作り直します。調整済みデータを初期化するため、通常のプレイには不要です。

Androidではシーン開始時に縦向きにします。既存プロジェクトのBuild Profileは変更していません。端末へビルドする場合は、使用するAndroid Build Profileのシーン一覧に `Kazuma.unity` を登録してください。
